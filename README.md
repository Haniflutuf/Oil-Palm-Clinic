# Oil Palm Clinic

## Files
- `index.html` – the page and its logic
- `data.js` – all entries; edit this to add or correct problems
- `img/` – field photos

## Publish on GitHub Pages
1. Create a public repository, e.g. `Oil-Palm-Clinic`.
2. Upload `index.html`, `data.js`, `README.md` and the `img` folder.
3. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
